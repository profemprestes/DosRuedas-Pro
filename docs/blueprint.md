# **App Name**: DosRuedas Pro

## Core Features:

- Precision A4 Print Engine: Strict 210mm x 297mm CSS layout engine optimized for high-fidelity PDF export and printing.
- AI Route Optimization Tool: An AI-powered tool that analyzes logistical bottlenecks and uses reasoning to determine the most efficient B2B delivery routes.
- Corporate Logistics Dashboard: Real-time delivery tracking visualization featuring a responsive backdrop-blur card system for operations management.
- Alternating Content Canvas: A layout system that automatically alternates text and image positioning for dense, high-impact technical documents.
- Custom Font Rendering Pipeline: Optimized typography rendering using Next/Font for specific weight distributions required in legal documents.

## Style Guidelines:

- Primary background color is a deep indigo (#121F32), evoking the reliability of nighttime cargo and professional corporate environments.
- Primary accent color is a vibrant gold (#FDC322) used for high-visibility highlights, glowing effects, and calls to action.
- Headline and Title font: 'Space Grotesk' (SANS-SERIF) with heavy weights (700/900) for a techy, architectural look. Body font: 'Inter' (SANS-SERIF) for objective and legible document text.
- Utilitarian iconography using Lucide-react (Truck, Package, TrendingUp) styled with gold outlines and subtle glow effects.
- Strict A4 aspect ratio (210x297mm) container using Tailwind flexbox to balance a high-density Hero section and alternating service cards.
- Zero transition delay for printing states, with subtle hover elevation on surface cards (#1A2B44) in the web view.
